About AI Library

A short guide to what this platform does and how the recommendations are calculated.

What is AI Library?

AI Library is a final-year BCA project: a personalized book recommendation system for a college library. Instead of showing every student the same catalogue, it ranks books using each student's interests, subjects and reading history.

How recommendations work

The system uses content-based filtering. Every book's category, subject, keywords and description are converted into a weighted text profile, and so is the student's interests, subjects and previously selected books.

TF-IDF (Term Frequency - Inverse Document Frequency) scores each word: common words like "book" get a low weight, while rare, meaningful words like "pointers" or "cosine" get a higher weight. Cosine similarity then measures how closely the student's profile and a book's profile point in the same direction, from 0 (no overlap) to 1 (identical). The five books with the highest score are shown, combining interests (70%) and reading history (30%) once a student has selected books before.

AWS cloud architecture

The frontend is static HTML/CSS/JS hosted on Amazon S3. Every request goes through Amazon API Gateway to an AWS Lambda function written in Python, which reads and writes Amazon DynamoDB (students, books, reading history) and Amazon S3 (dataset and cover images). An IAM role gives Lambda only the permissions it needs.

Privacy and security

Sign in on this demo is a browser-only convenience layer for navigating the multi-page app; it is not a production authentication system and should not be used with a real password you reuse elsewhere. The student profile (interests, subjects) is stored in DynamoDB through the real backend API.
